## 这个文档是什么，怎么用

这是你在这个项目里的**工作台**，也是我们两个人之间保持同步的方式。

**对你来说：** 打开这里就知道现在要做什么、做到哪了、参考文档在哪。不用翻其他地方。

**对我们合作来说：** 你在这里更新状态，我就不需要单独来问你进展了——你的进度对我直接可见。遇到问题或者不确定的时候，把状态改成 ❓，我看到了会来找你聊。

**怎么更新：** 改 emoji 就行，不需要写说明。

```
🔲 待做  →  🔄 进行中  →  ✅ 完成
                           ❓ 有问题或需要对齐
```
