## 节点设计细节

### 入口屏
- 和 Lisa 的 Entrance.png 一致
- START → 淡入过渡到酒吧场景
- QUIT → 装饰性按钮（或关闭页面）

### Bar Scene 主场景
- Phoenix 冷淡开场一句话，然后等
- 对话框在右侧或底部，像素风样式
- 6 个酒瓶可点击，每个注入不同 context：
  - 点 Gin → Phoenix："Gin. Interesting." 然后追问
  - 点 Whisky → Phoenix："Classic. 你是哪种人？"
- Phoenix 全程说英文，语气冷淡，偶尔刻薄

### AI 海报生成
- Phoenix 推荐后，画面出现鸡尾酒卡片
- 卡片内容：配方名 + 配料 + 步骤 + Phoenix 风格短评
- 视觉：老式酒吧菜单卡，像素风格
- 用 Claude API 生成文字内容，Lisa 设计卡片样式

### Mixing Game
- 从对话中自然触发（用户主动说"我想试试"）
- 5 轮多选题，每轮是一个调酒步骤判断题
- 失败台词用 Phoenix 真实语气：
  - "This is painful to watch."
  - "Did you even try?"
- 成功时 Phoenix 只是点头，不夸你

## 与三个来源的对应

| 来源 | 保留了什么 |
|---|---|
| **Direction A** | Phoenix 全程开放对话，无强制流程，可以就聊 |
| **Direction B** | 完整弧线：聊天 → 追问 → 推荐 → 海报 |
| **Lisa 的设计** | Mixing Game + AI 海报 + Phoenix 刻薄台词 |

Browse Menu 整体去掉，Recipe 数据变成 Mixing Game 题目来源和 Phoenix 的知识库。
